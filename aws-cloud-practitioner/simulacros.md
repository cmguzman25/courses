## Completos (65 preguntas, 90 min)

Condiciones reales: cronómetro, sin apuntes, sin pausas, de una sentada.

| | | | | |

**Regla:** no agendes el examen hasta tener **2 simulacros seguidos ≥ 800**.
El corte real es 700, pero los simulacros buenos son más duros que el examen;
apuntar a 800 te da margen para el día malo.

## Después de cada simulacro completo

1. Revisa **todas** las preguntas, también las acertadas. ¿Lo sabías o adivinaste?
2. Vuelca cada fallo en `bitacora.md` con su causa real.
3. Convierte cada fallo en una tarjeta nueva de Anki.
4. Si un dominio concentra los fallos, reabre ese módulo antes de seguir.

## Gestión del tiempo el día del examen

- 90 min / 65 preguntas ≈ **80 segundos por pregunta**.
- Primera pasada: contesta lo que sabes, marca las dudosas y sigue. No te atasques.
- Segunda pasada: las marcadas.
- No dejes ninguna en blanco: no penalizan los fallos.
- Palabras clave a subrayar: *más rentable*, *menos esfuerzo operativo*, *más disponible*,
  *MÁS rápido de implementar*. Suelen decidir entre dos respuestas casi iguales.
