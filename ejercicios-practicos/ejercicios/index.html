Ejercicios prácticos

Abre un enunciado, escribe tu consulta en pgAdmin (localhost:5051, base practice) y pásasela a Claude para corregirla y registrarla.

SQL · PostgreSQL

Modelo de datos (base practice)

customers(customer_id, first_name, last_name, email, city, signup_date)
categories(category_id, name)
products(product_id, name, category_id → categories, price, stock)
employees(employee_id, first_name, last_name, job_title, manager_id → employees, salary, hire_date)
orders(order_id, customer_id → customers, employee_id → employees, order_date, status)
order_items(order_id → orders, product_id → products, quantity, unit_price)

status puede ser pending (pendiente), shipped (enviado), delivered (entregado) o cancelled (cancelado). El importe de una línea es quantity * unit_price.
