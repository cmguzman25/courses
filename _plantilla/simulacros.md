# Simulacros

## Por módulo

Corto (10–20 preguntas), al cerrar cada módulo. Umbral: **80%**.

| Fecha | Módulo | Nota | Fallos → bitácora |
|-------|--------|------|-------------------|
| | | | ⬜ |

## Completos

En condiciones reales: tiempo cronometrado, sin apuntes, de una sentada.
Umbral para presentarte de verdad: **2 simulacros seguidos por encima del corte real**.

| Fecha | Simulacro | Nota | Tiempo | Área más débil |
|-------|-----------|------|--------|----------------|
| | | | | |

## Después de cada simulacro completo

1. Revisa **todas** las preguntas, también las acertadas (¿acertaste o adivinaste?).
2. Vuelca cada fallo en `bitacora.md` con su causa.
3. Convierte cada fallo en una tarjeta de Anki nueva.
4. Si un módulo concentra los fallos, vuelve a abrirlo. No sigas adelante.
